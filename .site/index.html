Firmware Compilation Workflows

Out-of-tree CMake & Makefile build orchestration for MicroPython and CircuitPython ports.

MicroPython USER_C_MODULES Compilation

# Clone micropython and cmods workspace side-by-side:
git clone https://github.com/micropython/micropython.git
git clone https://github.com/PyDevices/cmods.git

# Compile ESP32-S3 firmware with displayif and lvgl usermods enabled:
cd micropython/ports/esp32
make USER_C_MODULES=../../../../cmods/micropython.cmake BOARD=ESP32_GENERIC_S3

CircuitPython Out-Of-Tree Build Patching

# Apply PyDevices usermod patch set to CircuitPython tree:
cd cmods
./apply_cp_patches.sh --cp-dir ../circuitpython

# Compile CircuitPython unix desktop simulation or MCU board target:
cd ../circuitpython/ports/unix
make -j VARIANT=coverage
